3Safety rules (enforced in code)

  • Read-only by default. An edit needs your words + time (--approved) and a folder (--write-scope).
  • Refused before anything runs: skip-permissions, bypass, yolo, --force, auto, full-access, and any permission flag from CK.
  • Cursor auto = allow-all (--force) + mandatory Claude review; agy auto = --mode auto + workspace & run folder dirs + the same review (approved by chalach, 2026-11-03). Flags writes outside the task folder, raw folders, deletions, push, uploads, credentials, paid cloud.
  • Raw folders are read-only (real path checked too). NV: agents write only in NV Project/ and AQS/ (the cursor/agy review accepts nv AQS/ edits too).
  • No credentials: clean env, no keys. Claude is denied ~/.ssh, .env, *auth*, *credential*, keychains.
  • No push, deploy or send; no paid cloud sims; no venv or clone in OneDrive.
  • After each run: disk + log check. Flagged (4) or violation (5) stops the chain.
  • Runs in parallel, no workspace lock (2026-11-03). Edit runs claim their write folders automatically; --claim adds other files. Busy (6) = claim conflict. A number with no source is tagged UNVERIFIED.
